# Biblioteca_Universidade

Sistema de gerenciamento de acervo e usuários desenvolvido em C.

## Funcionalidades:

- Cadastro, consulta, atualização e remoção de livros (CREATE - READ - UPDATE - DELETE).

- Gerenciamento de estudantes e controle de empréstimos.

- Persistência de dados em arquivos.

**Tecnologias:** Linguagem C, Ponteiros, Manipulação de Arquivos.

## Como compilar e executar:

1. Clone o repositório: 
```bash
git clone https://github.com/AndreaLindote/Biblioteca_Universidade.git
```

2. Compile o código:
```bash
gcc main2.c funcoes2.c -o programa
```

3. Execute: 
```bash
./programa
```
